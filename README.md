# 🎓 CGPA Calculator

A simple and interactive **CGPA Calculator** built using **HTML, CSS, and Vanilla JavaScript** as part of the **HackWeek Frontend Challenge**.

## ✨ Features

- 📚 Add multiple subjects dynamically
- 🎯 Select grades using a dropdown
- 📊 Calculate Semester GPA instantly
- 📈 Calculate Updated CGPA based on previous semesters
- 🔮 "What If" Mode to predict future CGPA
- ❌ Delete subjects when needed
- 🔄 Reset all inputs with a single click
- 📱 Responsive and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

cgpa-calculator/

## 📖 About

This project was developed as part of the **HackWeek Challenge 2026**. The goal was to create an interactive GPA/CGPA calculator that allows students to calculate their semester GPA, update their cumulative CGPA, and simulate future semester performance using a "What If" mode.

The application is built entirely with HTML, CSS, and Vanilla JavaScript without using any external libraries or frameworks.
